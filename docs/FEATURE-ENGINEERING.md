## 6. Continuous Normalization (Min-Max Scaling)
Proportional linear transformation ensuring values fall strictly between $0.0$ and $1.0$.

### 6.1. Minimization Criteria (Costs)
* **Formula:** $Score = \frac{\max(X) - X}{\max(X) - \min(X)}$
* **Applied Columns:** `cost`

### 6.2. Maximization Criteria (Benefits)
* **Formula:** $Score = \frac{X - \min(X)}{\max(X) - \min(X)}$
* **Applied Columns:** `warranty`, `engine`, `horsepower`, `torque`, `city_fuel_economy`, `highway_fuel_economy`, `payload_capacity`, `aesthetics`, `freshness`
